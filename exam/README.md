Step 1. Students log in on student workstations. Some students need their mobile phones to complete login.

学生在学生机登录账号，部分学生需要手机协助登录。 

<br>

Step 2. Ensure every student opens the secure browser. Individual confirmation is required.

确保每位学生打开安全浏览器。需要逐一确认。

<br>

Step 3. Students navigate to the page for entering the access code. DO NOT announce the access code at this stage.

学生进入输入访问码（access code）的页面。现在不告知access code。

Step 4. Collect mobile phones and electronic devices using the trolley (C315). We may not achieve full collection, but this step establishes the rule for cheating enforcement: any student found using an electronic device afterwards will receive a zero for the exam.

使用小推车(C315)收取手机及电子设备。虽然无法保证全部收齐，但该步骤作为作弊认定依据：后续一经发现使用电子设备，本次考试记 0 分。 

Step 5. Verify student names. Quick check against the list on the instructor PC; conduct detailed verification if there are doubts.

核对学生姓名：对照教师机名单快速核查，存疑时再仔细复核。 

Step 6. Orally announce the access code and start the exam.

口头公布访问码，开始考试。

Step 7. Late students cannot start the exam immediately. A batch of late students will be allowed to start 30 minutes after the official exam begins. Anyone arriving more than 30 minutes late will receive a zero.

晚到的同学不随时开始，而是开考30分钟后开始一批。超过30分钟没到的记0分。

Step 8. Students who finish the exam must leave the exam room immediately. If necessary, the instructor will specify when they may return to the classroom.
做完的同学必须立刻离开考场，如果有需要，由教师指定回到教室的时间。
